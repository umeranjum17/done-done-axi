# Affected file proof

`done-done verify --affected-by <file>,<file> [--extends <head>] --outcome "<claim>"` proves a head that changed under a receipt (a rebase, say) by driving only the journeys the named files affect. The selection is `done-done affected`'s own (`src/affected.ts`): a file a journey's command reaches selects that journey, and a file no journey covers, or a configured global one, selects the whole `local` tier. The journeys run one verify run after another, with no fix attempt (`--fix-tries` is refused); a feature no journey drives is refused with the command that drives it. `--extends` names the head of the prior receipt (default: the newest receipted ancestor of HEAD; after a rebase the old head is no ancestor, so name it). The receipt carries `affected: {extends: {head, sha256, review}, files, journeys, ran, review: "not run again"}` and a `skipped` review whose reason names the prior receipt. It is valid only once every selected journey has run, and `receipt --verify` fails if the prior receipt's file is gone or changed. It writes no journey and starts no reviewer. `--affected-by` beside a journey, `--journeys` or `--feature`, `--extends` alone, `--extends HEAD`, and a prior head with no receipt are usage errors (exit 2).

Source: `src/affected-proof.ts` (`parseFiles`, `affectedProof`, `extendReceipt`, `affectedShape`), `src/cli.ts` (`verifyAffected`, `priorReceipt`, `recordReceipt`, `receiptFault`, `verifyReceipt`), `dist/affected-proof.js`, `dist/cli.js` and `journeys/affected-proof.mjs`.

Drive: `done-done run affected-proof` builds a throwaway app with two local-tier journeys that each import their own source, a feature commit with a receipt, a stub judge and a reviewer stub that records any start (review stays on). It rebases onto a main that changed one journey's source and runs `verify --affected-by src/bob.js --extends <old head>`; then rebases onto a main that added `docs/NOTES.md` (no journey covers it) and runs `verify --affected-by docs/NOTES.md`. It reads `receipt --verify HEAD` after each, tries the refused forms, and changes the prior receipt's file.

Prove: affected-proof.log shows the first run driving only `greet-bob` (the receipt's `affected.journeys` and `ran` are `greet-bob`, `extends.head` is the old head, `extends.sha256` is the hash of that receipt file, `review` is `not run again`); the second driving `greet-ann` and `greet-bob` in one receipt holding both captures; `receipt --verify` passing each; no reviewer started; the refused forms exit 2; and a changed prior receipt failing with `whose file changed since`.
