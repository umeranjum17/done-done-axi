# Registered test-script updates

`journey enhance <name>` and `journey improve <name> "<instruction>"` accept a journey whose command runs a registered test script: Node (`node test/export.test.mjs`, `node --test test/x.test.mjs`) or Bash (`bash tests/greet.test.sh > "$DONE_DONE_EVIDENCE_ROOT/${RUN_ID}.log" 2>&1`, redirections kept). The script is rewritten in place, the journey's command is kept, no second `journeys/<name>.mjs` is written, and the script's hash in `.done-done-inventory.json` is updated, so `done-done lint` passes. Invalid Bash is refused before any write with `invalid Bash; nothing written` and the `bash -n` syntax error. Inventory owns named `*.test.sh` / `*.spec.sh` files and any script a journey runs; other `.sh` helpers are not stray tests. A script missing from the inventory is refused with the `inventory record` command to run. The output begins `Stage writing: <file>` and so names the file written. Source: `src/inventory.ts` (`entryScript`), `src/cli.ts` (`cmdJourney`).

Drive: `done-done run registered-script` builds two throwaway repos. The first runs the Node test `node test/export.test.mjs`: `journey improve` with a stub agent (no model, no spend), then `done-done lint`. The second, a greeting CLI for Umer, runs the Bash test `tests/greet.test.sh` with evidence redirected into `$DONE_DONE_EVIDENCE_ROOT`: `journey improve` (dirty trial, clean replay) and `journey enhance`, each committed and run through `done-done run`; a stderr regression fails the run; invalid Bash and an unregistered Bash test are refused.

Prove: `registered-script.log` shows `journey improve tool-run` exit 0 with `Stage writing: test/export.test.mjs` and `test/export.test.mjs | 1 +` in the diff, then `done-done lint` printing `PASS`. No screen: the proof is the run's text log.

Integration coverage: none yet in test/cli.test.mjs; the journey is the proof.
